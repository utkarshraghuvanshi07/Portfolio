# 💻 Personal Portfolio Website

A modern and interactive personal portfolio website built to showcase my skills, projects, education, experience, and contact information.

The website focuses on a clean developer-oriented design with smooth scrolling animations, interactive project cards, skill progress bars, and a responsive navigation system.

## ✨ Features

* 🎯 Hero section with typewriter introduction
* 👨‍💻 About Me section
* 🛠️ Skills and technology showcase
* 📊 Animated skill progress bars
* 🚀 Projects section with interactive cards
* 🖱️ 3D hover effect on project cards
* 📜 Experience / timeline section
* 🎓 Education section
* 📩 Contact section
* 📱 Responsive navigation with mobile menu
* 🎨 Smooth scroll-based animations
* ♿ Reduced-motion support for accessibility
* ⚡ GSAP and ScrollTrigger animations

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GSAP
* GSAP ScrollTrigger
* Responsive Web Design

## 🎬 Animations & Interactions

The website uses GSAP and ScrollTrigger to create interactive animations throughout the page.

Some of the animations include:

* Hero content entrance animations
* Typewriter text effect
* Section reveal animations
* Skill bar animations
* Project card entrance animations
* Project card 3D tilt effect on hover
* Timeline line drawing animation
* Timeline item and dot animations
* Education card animations
* Contact section animations
* Mobile navigation toggle

The website also checks the user's `prefers-reduced-motion` setting and reduces the animation experience when requested by the system.
